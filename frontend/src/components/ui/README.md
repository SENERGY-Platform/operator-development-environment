# Vendored components

Everything in this directory is generated by the shadcn CLI and copied in as
source. It is **not** ODE code and does not carry the InfAI Apache-2.0 header the
rest of `src/` does.

| Origin | License | Reaches here as |
|---|---|---|
| [shadcn/ui](https://ui.shadcn.com) | MIT | the files in this directory, written by `npx shadcn add` |
| [`@shadcn/react`](https://www.npmjs.com/package/@shadcn/react) | MIT | a runtime dependency, behind `questionnaire.tsx` and `message-scroller.tsx` |
| [Base UI](https://base-ui.com) | MIT | a runtime dependency, `@base-ui/react`, behind most of the rest |
| [Lucide](https://lucide.dev) | ISC | a runtime dependency, `lucide-react` |
| [tw-animate-css](https://github.com/Wombosvideo/tw-animate-css) | MIT | a runtime dependency, imported by `src/index.css` |
| [Source Sans 3](https://github.com/adobe-fonts/source-sans) | OFL-1.1 | a runtime dependency, `@fontsource-variable/source-sans-3`, bundled by the build |

MIT, ISC and OFL-1.1 are all permissive and all allowed by
`.claude/license-policy.env`. None of them obliges us to relicense; all of them
oblige us to keep the notice, which is what this file is. OFL-1.1 additionally
forbids selling the font on its own and requires that any *modified* version be
renamed — neither of which we do: the font is bundled unmodified as a web asset.

## Regenerating

`components.json` pins the preset (`base-vega`: Base UI, `mist`, CSS variables).
`npx shadcn@latest add <name> --overwrite` rewrites a file here from that preset,
so **local edits to these files are lost on regeneration**. There is exactly one,
recorded here so a regeneration can reapply or drop it deliberately:

- `scroll-area.tsx` — the generated file imports `React` without using it, which
  `noUnusedLocals` rejects. The import is removed.

One further difference is worth knowing but is *not* an edit here, because it is
applied by the caller instead: `message-scroller.tsx` gives every item
`content-visibility: auto` with a 10rem intrinsic size, which makes scrolling a
transcript of wildly varying turn heights jump. `chat.tsx` overrides it per item
rather than changing the component, so a regeneration cannot silently undo it.

Anything larger than that belongs in a wrapper under `src/`, not in an edit here.
